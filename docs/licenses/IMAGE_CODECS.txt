HEIC / HEIF
This version does not bundle or download an HEVC codec, libheif, libde265,
or their source archives. It uses the user's browser's native image support.
If native decoding fails, users are directed to a compatible Safari version
or a trusted local converter to export a JPEG/PNG copy. Safari support is
conditional on the OS, browser and actual image. Video import is not supported.
Native browser support is not a project-wide patent non-infringement warranty.
