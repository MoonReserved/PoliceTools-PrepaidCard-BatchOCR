Bundling notes:
- pdf.min.mjs and pdf.worker.min.mjs are unmodified legacy-build files.
- Decoder fallback JS files are unmodified upstream files.
- CMaps, standard fonts, decoder WASM, and an ICC profile are concatenated unchanged into resources.pack.
- resources.json records each original file path, byte offset, length, and SHA-256.
- The application supplies a custom BinaryDataFactory with useWorkerFetch:false to read this local pack.
- No PDF viewer, scripting sandbox, QuickJS interpreter, or external CDN is included.
- PDF.js 6 removed the older isEvalSupported option; a false value must not be described as an active 6.x control.
- useWorkerFetch:false disables PDF.js optional ICC WASM color management; built-in color-space fallback remains.
- The legacy build broadens syntax/API compatibility but does not guarantee all older browsers or mobile devices.
- Browser rendering uses local bytes, bundled resources, canvas-only output, disableFontFace:true, useSystemFonts:false, and enableXfa:false.
