本機使用請開啟啟動工具

若你直接點了 index.html，請回到解壓縮後的專案資料夾，雙擊對應的啟動檔：

macOS：START_MAC.command
Windows：START_WINDOWS.bat

啟動後會自動開啟本機網址；不必安裝 Python，也不會上傳圖片。若從正式網站開啟仍看到此提示，請確認瀏覽器允許這個網站執行 JavaScript。

尚無完成結果

輸出採用上方清單的順序。複製與 TXT 只含序號；CSV 的 order 欄保留介面序位，篩選後可能跳號。CSV 請用「匯入資料」並將文字欄指定為文字，避免前導零消失或以公式解讀。

v8.5.3 · 點框畫面穩定

圖片、PDF 與辨識結果只留在此分頁的記憶體，關閉或清空即移除。請在離開前匯出結果。離線快取只儲存程式、字型、公開模型與授權文件。

PDF 只轉成頁面畫面，不執行文件內的指令或開啟連結。顯示「完整離線就緒」後，可在同一瀏覽器、同一網址離線開啟。請保留網站資料；無痕模式、系統清理或清除快取可能移除離線資源。

使用模型與相關授權

文字位置偵測使用 PP-OCRv5 mobile DB；序號辨識使用 PP-OCRv6 small。模型來自 PaddleOCR，使用 RapidOCR 提供的 ONNX 轉換版本。

瀏覽器運算使用 ONNX Runtime Web 1.23.2；PDF 拆頁使用 PDF.js 6.4.299；介面字型使用 Noto Sans CJK TC 的本機字型子集。
